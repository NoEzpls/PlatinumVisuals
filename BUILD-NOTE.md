# Состояние сборки 1.6.0

Исходники рассчитаны на Minecraft 1.21.11 / NeoForge 21.11.45 и Java 21.

В изолированном окружении проверка исходников остановилась на задаче NeoForm до
`compileJava`: внешний manifest Mojang (`piston-meta.mojang.com`) недоступен.
Это инфраструктурное ограничение, а не ошибка Java-кода. На обычном компьютере
с доступом к manifest и скачиванию Minecraft запуск `gradlew build` должен
выполнить стандартную подготовку NeoForge и собрать новый JAR.
